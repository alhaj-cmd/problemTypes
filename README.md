# TypeScript Problem Solving Assignment

***এই অ্যাসাইনমেন্টে বিভিন্ন গুরুত্বপূর্ণ বিষয় যেমন function, array, interface, class, generics, union type এবং type guard নিয়ে কাজ করা হয়েছে। filterEvenNumbers, reverseString এবং getIntersection এর মতো ফাংশনের মাধ্যমে array ও string নিয়ে কাজ করার দক্ষতা দেখানো হয়েছে। Interface এবং class ব্যবহার করে object-oriented programming সম্পর্কে ধারণা পাওয়া গেছে। এছাড়া generics ব্যবহার করে type safety এবং reusable code তৈরি করার পদ্ধতি। এই problem solving assignment TypeScript-এর মৌলিক ধারণা ও বাস্তব প্রয়োগ---
